How you can check these dates

Commit dates can be set to anything, so I don't rely on them. Each entry links to its pull requests and commits on GitHub; the ones made on github.com are signed by GitHub with its own clock. Each entry is also stamped with OpenTimestamps, which anchors a fingerprint of the entry in the Bitcoin blockchain. That proves the entry existed by that block's time, and changing a single character breaks the proof. To check one yourself, download its entry file and proof and drop both on opentimestamps.org.

Every piece of evidence also shows its git commit ID. That's a SHA-1 fingerprint of the commit's contents and all the history before it, so a past commit can't be changed without changing its ID. Paste any ID after github.com/RSSGuy/kestrel-simulator/commit/ to see it, or run git show with it in a clone. The SHA-256 under each entry is the fingerprint of the entry file itself, which is what's anchored in Bitcoin.

Known Issues

On Nov 19, 2026 Claude audited the source of every published tutorial against the conventions I had been fixing one tutorial at a time. The audit found 4 problems that run across many tutorials. I rechecked the commit counts, the theme counts and the link count against the live files the same day. Until each one is fixed, it stays on this list.

Commit and Branch Reminders Open

13 tutorials never tell the learner to make a branch, commit the work, or push it.

Proof

The source of each of these tutorials contains no git commit, no git push and no branch instruction. The tutorials that do have reminders were built after my own lesson commits went straight to main on the Kestrel build.

Tutorials Business Logic from Zero, Docker from Zero, FastAPI from Zero, HTTP + Networking from Zero, Kubernetes from Zero, NGINX from Zero, OAuth from Zero, Observability from Zero, Playwright + pytest from Zero, Postgres from Zero, React + TypeScript from Zero, SQLAlchemy + Alembic from Zero, Test Cases from Zero

Test Cases from Zero has no terminal and writes no files, so it does not need them. Cloud Deploy from Zero pushes but never makes a branch. Tailwind + shadcn/ui and Wiring the Rules mention it only once.

In the meantime: Make a branch before each lesson, then commit and push at the end of it. Git Basics Sandbox shows how.

Windows Command Prompt Open

133 commands in 17 tutorials are written for bash and will fail in the Windows Command Prompt.

Proof

The commands use ls (55), cat (24), a VAR=value prefix (18), $var (17), pwd (7) and a few others. I found the first one myself, when ls -a failed on my own machine. Project Structure from Zero is the only tutorial that shows a Command Prompt form, and only for some steps.

Most of the simulated terminals accept the Windows form too, so the lesson still works. The command only fails when it is typed on a real Windows machine. OAuth from Zero is a special case: its commands build a PKCE code with shell substitution, which has no clean Command Prompt form.

In the meantime: On Windows, use Git Bash, which is installed with Git for Windows. It runs these commands as written.

Further Reading Links Open

About 400 links to outside documentation have not been checked.

Proof

Some of the further reading links were written from memory rather than clicked, so some may have been wrong the day they were published. The rest have had weeks to go out of date. The audit could not reach the web, so none of them were tested.

The most linked sites are docs.docker.com, postgresql.org, kubernetes.io, react.dev and docs.github.com.

In the meantime: If a link fails, search the documentation site for the page title.

Theme Consistency Decision pending

The Kestrel theme is not applied the same way in every tutorial.

Proof

CI from Zero and OAuth from Zero never mention the Kestrel, so a learner who follows the path in order loses the theme and finds it again. Kubernetes from Zero and NGINX from Zero name the suit without the Mk II mark. The blueprint drawing exists in 12 different versions across 14 tutorials, because each one carries the drawing as it was on the day it was built.

Tutorials CI from Zero, OAuth from Zero, Kubernetes from Zero, NGINX from Zero

This does not change what any lesson teaches. For CI and OAuth I still have to decide whether to retheme them or to say in each one that it sits outside the Kestrel story.

What the Audit Did Not Check

The audit only read the source text, so a problem that is not on this list may still exist. It did not check:

  • Whether the lessons teach correctly. That needs a person working through each tutorial, which is what the progress log records.
  • Whether the labs still pass. No tutorial was run in a browser.
  • Whether every step says which folder it runs from, and where a new file goes.
  • Whether every analogy gives the real term beside it.
  • Whether any link still works.
